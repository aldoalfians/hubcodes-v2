# nerd-symbols-mono.woff2

A subset of **Hack Nerd Font Mono** (Nerd Fonts v3 patch of Hack 3.003) that keeps only the icon ranges: `U+E000–F8FF`, `U+F0000–FFFFF`, `U+23FB–23FE`, `U+2665`, `U+26A1`, `U+2B58`. Produced with `pyftsubset … --flavor=woff2 --no-hinting --desubroutinize`.
